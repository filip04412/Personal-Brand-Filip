# Personal Brand - Filip Löndén Berntsson

Personlig portfolio och webbplats för Filip Löndén Berntsson – Digital Marketing Specialist-student på IHM Business School i Göteborg.

## Innehåll
- `index.html` - Webbplatsens struktur och innehåll
- `style.css` - Responsiv design med stöd för mörkt och ljust läge
- `script.js` - Interaktivitet (tema-växlare, visa mer, kopiera e-post)
- `img/` - Mapp för bilder och projektgrafik
- `Inspo/` - Inspiration och referensmaterial

## Teknologier
- HTML5
- CSS3
- JavaScript (Vanilla)
